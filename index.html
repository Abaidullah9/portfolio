FINAL YEAR PROJECT (FYP) — LITHO PUBLISHING ECOSYSTEM

★ CAPSTONE ENGINEERING PROJECT
Department of Computer Science • UET Lahore

Litho: A Template-Driven Markdown-to-LaTeX Publishing Ecosystem for Reproducible Technical Documents

End-to-end technical publishing with CommonMark syntax, schema binding, and lossless round-trip metadata recovery

Litho is an academic and technical document publishing ecosystem with full round-trip fidelity. Authors write extended CommonMark Markdown; a custom Python interpreter parses it, binds it to versioned publisher LaTeX templates via formal schemas, compiles it through an optimized Tectonic engine fork, and embeds the complete Markdown source and template ID into the PDF’s XMP metadata for guaranteed source recovery.

Abaidullah Bhatti — Core Ownership & Deliverables

  • Template-Binding Compiler (F4): Engineered schema resolution routines mapping parsed CommonMark AST nodes into structured publisher LaTeX templates.
  • LaTeX Code Generator (F5): Developed high-fidelity Jinja2 and format-string LaTeX emission handling shortcodes, callouts, equations, figures, citations, and Gantt charts.
  • Litho-Optimized Tectonic Backend (F6): Configured a trimmed Tectonic TeX fork with precompiled formats and subprocess orchestration for deterministic builds.
  • Golden-PDF Regression Testing (F22): Built an automated visual regression harness in CI verifying pixel-diff fidelity across thesis, IEEE paper, and technical book templates.

Ecosystem Architecture & Team Collaboration

Project Team: Abaidullah Bhatti (Compiler Lead), Rabia Nadeem (Parser/AST), Abdul Rahman (CLI/MCP Server), Sohaib Shaukat (Marketplace/VS Code).
